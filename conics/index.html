BEGINNER'S GUIDE

二次曲线系 · 零基础详解

先记一句话：几个点同时属于两条基础曲线，它们的任意加权组合曲线也一定经过这些点。

f + λg = 0

f、g 是两个关于 x、y 的式子；λ 只是一个可以改变的参数。

01 曲线为什么由方程决定？

把点的坐标代入含 x、y 的式子，结果等于 0，就说明这个点在曲线上。所有结果为 0 的点组成这条曲线。

例如 x²+y²−25=0 是半径 5 的圆。代入 (3,4)，结果是 9+16−25=0，所以它在圆上；代入 (1,1)，结果不是 0，所以它不在圆上。

“在曲线上”就是“代入方程后等于 0”。
02 两条直线怎么变成一个方程？

两个数相乘等于 0，至少有一个数是 0。因此 (x−y)(x+y)=0 表示 x−y=0 或 x+y=0，也就是两条直线 y=x、y=−x。

它展开后是 x²−y²=0，最高次为二次，所以两条直线合起来也可以看成一条“退化的二次曲线”。

乘积为零不是阴影区域，而是因式对应的曲线合并在一起。
03 原图中的椭圆和两条直线

紫色椭圆为 f=4x²+9y²−36=0。除以 36 得 x²/9+y²/4=1，所以横向半轴是 3，纵向半轴是 2。

蓝色双直线为 g=(3x−5y+3)(3x+5y+2)=0。因为乘积为 0，所以点只有在 3x−5y+3=0 或 3x+5y+2=0 上。

04 A、B、C、D 为什么固定？

四个交点同时属于椭圆和两条蓝线。以 A 为例：f(A)=0、g(A)=0。

代入曲线系：

f(A) + λg(A) = 0 + λ×0 = 0

因此 λ 无论取 −10、0、1、100，A 都仍在曲线上。B、C、D 同理。

公共交点拥有两张基础曲线的“双重通行证”，任何组合曲线都不能拒绝它们。
05 λ 到底改变什么？

λ 不是角度，不是长度，也不是曲线条数。它表示两个基础方程在组合中的比例。

λ=0 时，f+0×g=f=0，只剩原来的椭圆。

λ=1 时，f+g=0，化简为 13x²−16y²+15x+5y−30=0。x² 项系数为正，y² 项系数为负，所以是双曲线。

绿色曲线向屏幕外继续延伸不是画错。双曲线本来就有两条无限延伸的分支，画布只是截断了它们。
06 为什么五个点能确定二次曲线？

普通二次曲线为 Ax²+Bxy+Cy²+Dx+Ey+F=0。六个系数可以同时乘同一个非零数，所以真正独立的是五个自由度。

一个点提供一个条件。前四点留下一个参数 λ；第五点用来求它：

f(P₅)+λg(P₅)=0
λ=−f(P₅)/g(P₅)

只要 g(P₅)≠0，λ 就唯一确定。

07 用正方形四点看懂整件事

取 A(−1,1)、B(1,1)、C(1,−1)、D(−1,−1)。

直线 AB、CD 组成 F₁=(y−1)(y+1)=y²−1；直线 AC、BD 组成 F₂=(x−1)(x+1)=x²−1。

所有经过四点的曲线可以写成：

y²−1+λ(x²−1)=0

λ=0 得到两条水平线；λ=1 得到圆 x²+y²=2；λ=2 得到椭圆 2x²+y²=3；λ=−1 得到两条对角线 y=x、y=−x。

08 考试里的标准步骤
  1. 找到两组具有相同四个交点的曲线。
  2. 把它们分别写成 f=0、g=0。
  3. 设曲线系为 f+λg=0。
  4. 代入第五点、切线、对称性或已知系数。
  5. 求出 λ，代回并化简。

它的“降维”之处是不必求出四个交点的坐标，而是直接利用“四个公共点”这个整体条件。

09 新手最容易错的五件事
  1. g=0 是两条直线本身，不是两条直线之间的区域。
  2. λ 改变形状，但不会移动四个公共交点。
  3. 不同 λ 不一定是同一种曲线，可能从椭圆变成抛物线或双曲线。
  4. 两条蓝线自己的交点不一定在椭圆上，不能把它误认成 A、B、C、D。
  5. 双曲线到达屏幕边缘并不意味着曲线结束。
