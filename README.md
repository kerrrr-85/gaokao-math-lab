# 函数与导数 · 高考数学学习台

新高考全国卷方向、面向高三冲刺的**单用户、本地优先**数学学习台。用「课标骨架 + 解题方法卡 + 例题自测 + 间隔重复 + 错题本 + 知识图谱 + 搜索」构成完整学习闭环。

## v106 云空间主题

- 首页已改为视觉漫游优先的「我们的云空间」，不再展示任务倒计时、掌握度或刷题压力。
- 首屏与光影画廊使用项目内七张图片，可全屏欣赏。
- 风铃、地球和隐藏彩蛋作为可玩体验保留。
- 原学习功能完整保留，但收纳在首页底部「需要学习时，再打开工具」抽屉中。
- 首次进入会显示一次视觉欢迎页，不自动弹出每日计划。

## 功能
- **今日**：按间隔重复算法安排复习队列与新卡
- **知识图谱**：12 个知识节点与先修关系，点击查看详情、显示掌握度
- **方法卡**：识别信号 → 步骤 → 公式 → 易错点
- **练习**：按节点/难度/题型筛选，支持交错练习；选择、填空自动判分，解答题自评
- **错题本**：自动收集错题，可按「知识/方法/计算/审题/心态」归因，支持重做
- **统计**：正确率、各节点掌握度、错因与难度分布
- **搜索**：知识点、方法卡、题目全文检索
- **数据**：进度只存本机 localStorage，支持导出/导入 JSON

## 内容规模（v1）
- 12 个知识节点
- 24 张解题方法卡
- 48 道例题/自测题（基础 12 / 中档 24 / 压轴 12）

知识边界参考教育部《普通高中课程方案和课程标准（2017 年版 2020 年修订）》数学主题；例题为自编/改编并标注来源，不含受版权保护的真题原文。

## v4 新功能：手写 / 语音 / AI 讲解

- **数学符号面板**：填空、解答、思路框上方都有「∑ 符号」，分运算/关系/代数/函数/希腊字母/常用片段六组，点一下插入光标处。
- **手写画布**：点「✍️ 手写」用手指或触控笔书写，支持撤销/清空，完成的图片会随答案一起交给 AI 识别。
- **语音输入**：点「🎤 语音」说话，自动把“x的平方/大于等于/根号”等转成数学符号（安卓 Chrome/Edge 支持）。
- **语音朗读**：答题后可「🔊 朗读解析」，设置里可调语速与音色。
- **AI 讲解**：答题后点「🤖 AI 讲解」，会指出**思路在哪一步错了、为什么错、正确步骤**；未配置或断网时自动回退到**离线规则版分析**。
- **你的思路栏**：所有题型都可写思路（文字/语音/手写），这是 AI 能定位错误的前提。

### 启用 AI 讲解（需要一次部署）
1. 按 `proxy/README.md` 把 Cloudflare Worker 部署好（API Key 只存在 Worker 里）；
2. 打开学习台 → 设置 → AI 讲解 → 填入代理地址 → 勾选启用 → 点「测试连接」；
3. 答题后点「🤖 AI 讲解」即可。手动触发，不点不花钱。

## v104 秒读训练

- 首页「秒读训练」入口或 `#/reading` 可直接使用，无需学校账号。
- 支持跟随高亮、中央闪读、240-1200 字/分钟调速和 1-3 分钟限时。
- 每篇结束后完成三道理解题，记录实际速度与理解率。
- 训练记录只保存在本机 `localStorage`（`gml_speedread_v1`）。
- 内容为本站自编通用阅读材料，不包含「秒读课堂」官方课程或账号数据。
