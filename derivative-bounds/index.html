18

已知函数 f(x) = ax − (x + b)/ex，曲线 y = f(x) 在点 (0, f(0)) 处的切线方程为 y = −x + 1。

  1. 求 a、b 的值；
  2. 证明 f(x) 在 (1, +∞) 上单调递增；
  3. 求函数 f(x) 的零点个数，并说明理由。
完整讲解在页面下方 ↓
函数图像 f(x) = x − (x − 1)e−x
拖动画布中的蓝点查看切线
橙色虚线：x = 0 处切线 y = −x + 1 绿色区域：f′(x) > 0
为什么 f′(x) 一定大于 0 把两个函数放在同一张图中
01 / 由切线求参数
切线过 (0,1)：f(0) = −b = 1，所以 b = −1
切线斜率 −1：f′(0) = a − 2 = −1
所以 a = 1
f(x) = x − (x−1)e−x
02 / 把单调性化成比较大小
f′(x) = 1 − (2−x)e−x
x ≥ 2：第二项 ≤ 0，所以 f′(x) > 0
1 < x < 2：两个正因子都小于 1
ex > 2 − x
03 / 判断零点
x ≥ 1：f(x) ≥ f(1) = 1 > 0
0 < x < 1：x 与 1−x 都为正
x ≤ 0：f(x) ≥ x + (1−x) = 1
所以零点个数为 0
老师思路

先别急着求根。切线同时给出函数值和斜率，第一问可以从这两个条件反推参数。

ex ≥ x + 1 ln x ≤ x − 1 ex ≥ e·x ln x ≤ x/e
最终答案 a = 1，b = −1，零点数 = 0
完整讲解稿

不是记几个结论，而是看懂为什么这样变形

建议顺序：先读思路，再看左边曲线；最后用“最低点法”验算一遍。

A

切线方程为什么能求两个参数？

切线经过切点，所以切点坐标必须满足切线方程。把 x = 0 代入 y = −x + 1，得到切点是 (0, 1)。原函数在 x = 0 的值是 f(0) = −b，因此 −b = 1，得到 b = −1。

切线还给出曲线在该点的变化方向：切线斜率是 −1，所以 f′(0) = −1。先代入 b = −1，再利用这个条件就能得到 a = 1。切线的“点”和“斜率”是两个独立条件，前者求 b，后者求 a。

f′(x) = 1 + (x−2)e−x = 1 − (2−x)e−x
B

第二问难的不是求导，而是判断正负

导数写成 1 − (2−x)e−x 后，直接令它大于零会得到一个无法轻松求解的混合方程。这里要按区间处理：x ≥ 2 时，2−x ≤ 0，所以减去的这一项不是正数，整个导数自然大于零。

真正需要观察的是 1 < x < 2。这时 2−x 和 e−x 都是正数且都小于 1，所以它们的乘积一定小于 1，单调性已经成立。视频继续把比较改写成 ex 与 2−x，是为了看清“放缩”从哪里来：因为 ex 已经大于 e，而 2−x 小于 1，所以前者显然更大。

ex > 2−x ⟹ (2−x)e−x < 1 ⟹ f′(x) > 0

这就是“放缩”的真正用途：不是随意把式子变大变小，而是换成方向确定、容易比较的量。

C

第三问为什么不直接解 f(x) = 0？

f(x) = x − (x−1)e−x 是超越函数，硬解零点既复杂又容易讨论不全。题目只问零点个数，因此只需证明函数图像在 x 轴上方或者下方，不需要真的把零点求出来。

由第二问，f 在 [1, +∞) 上递增，且 f(1) = 1，所以右半部分始终为正。0 < x < 1 时，x 是正数，而 x − 1 是负数，于是减号后也是正数，所以 f(x) 是两个正数之和。

f(x) = x + (1−x)e−x

x ≤ 0 时，1−x > 0，并且 e−x ≥ 1，因此第二项不小于 1−x；再与第一项 x 相加，结果至少为 1。三个区间都证明 f(x) > 0，所以零点个数是 0。

D

另一条路：先找函数的最低点

视频还演示了另一种更有代表性的做法。令 h(x) = ex + x − 2，则 h′(x) = ex + 1 > 0，所以 h 严格递增；且 h(0) = −1、h(1) = e−1 > 0，故存在唯一的 x₀∈(0,1)，使 h(x₀) = 0。

这个 x₀ 正好是 f′(x) = 0 的点：f′ 在左侧为负、右侧为正，所以 f 先减后增，x₀ 就是最低点。再利用 ex₀ = 2−x₀ 去掉指数项，得到：

f(x₀) = (−x₀² + x₀ + 1)/(2−x₀) > 0

因为 0 < x₀ < 1，分子大于 1，而分母小于 2，所以最低点也大于零。这相当于用另一种方式确认：整条曲线都在 x 轴上方。

E

四个常用放缩是怎么来的？

这些并不是需要死记的孤立公式，它们本质上都是曲线在某一点的切线。ex ≥ x + 1 来自 ex 在 x = 0 的切线；ln x ≤ x − 1 来自 ln x 在 x = 1 的切线。两条曲线分别位于切线的一侧，所以不等式方向固定。

把自变量换掉，还能得到另外两条常用结论：ex ≥ ex 在 x = 1 处取等，ln x ≤ x/e 在 x = e 处取等。遇到复杂函数时，不要急着求导到底，先想它能否换成这些简单的切线函数。

ex ≥ x+1　　ln x ≤ x−1　　ex ≥ ex　　ln x ≤ x/e
!

考场最容易错的地方

  • 只知道切点，不知道斜率；或者求出参数后忘记重新代回函数。
  • 用“两个因子都小于 1”做判断前，必须先确认两个因子都是正数；同时还要检查放缩后不等式方向是否一致。
  • 讨论零点时只看了 x ≥ 1，漏掉 x 为负和 0 < x < 1 的情况。
  • 放缩方向与题目要求的方向相反，例如把需要证明大于零的式子放成了更大的式子。
