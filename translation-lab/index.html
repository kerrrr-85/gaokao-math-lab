CLASSICAL CHINESE / WORD MEANING IN CONTEXT

讽、直一也

一句话里，藏着一组反义词、六个“一”和八个“顾”

吾以为讽、直一也，顾用之之术何如耳。

整句翻译我认为委婉的劝谏、直白的劝谏在本质上是一样的，只是使用它们的方法怎么样罢了。

这句话真正要判断的 不是“讽”和“直”谁更好，
而是“方法是否恰当”。

顾用之之术何如耳。
= 只是使用它们的方法怎么样罢了。

前文先分高低，作者马上反驳

前文观点

古今论谏，常与讽而少直。其说盖出于仲尼。

古往今来谈进谏，常赞许委婉的“讽”，轻视直白的“直”。 与 = 赞许；少 = 轻视、贬低
→
作者判断

吾以为讽、直一也。

我却认为讽谏和直谏本质相同，没有天然的高下。 一 = 一样，相同；也 = 判断语气
→
真正结论

顾用之之术何如耳。

关键只看使用它们的方法是否合适。 顾……耳 = 只是……罢了
01

逐字拆开

每个采分点，都要能回到例句

吾第一人称代词

“吾”就是“我”。文言文中的自称很多，判断时通常根据说话人与上下文。

常见自称：吾、余、予、仆、臣、愚、鄙人、小人、寡人、孤。

“吾以为”中的“吾”作主语，“以为”后面接作者的观点。

以为两个高频结构

义项一：以（之）为

把……作为、当作或制成……

  • 仁以为己任。《论语》十二章：把实现“仁”作为自己的责任。
  • 纫秋兰以为佩。《离骚》：把秋兰连缀起来，制成佩饰。

义项二：认为

  • 自以为得其实。《石钟山记》：自己认为已经得到了事情的真相。

本句：吾以为 = 我认为

讽 / 直两种进谏方式

讽谏

用委婉含蓄的话规劝，不直接批评，常借寓言或生活小事旁敲侧击。

典型：《邹忌讽齐王纳谏》 邹忌以妻、妾、宾客赞美自己的生活小事，类比齐王受蒙蔽，劝其广开言路。

直谏

当着君主的面直接指出过错，不加回避，表达鲜明直接。

典型：魏征进谏 视频用魏征作为直谏代表，帮助区分“讽”和“直”的表达方式。
一本句取“一样、相同”
①数词，一最基本的数目。
②第一一鼓作气，再而衰，三而竭。第一次击鼓。
③专一、专注用心一也。《劝学》中表示用心专一。
④全都、一概而或长烟一空。大片烟雾完全消散。
⑤一样、相同古今一也。从古至今都一样。
⑥统一六王毕，四海一。天下归于统一。

判断理由：前文把讽、直分出高低，作者却说“讽、直一也”，显然是在抹平这种差别。

顾动词五义，副词三义

作动词

  1. 回头看赢得仓皇北顾。
  2. 看，视相顾无言，惟有泪千行。
  3. 探望，拜访三顾臣于草庐之中。
  4. 顾惜，考虑大行不顾细谨，大礼不辞小让。
  5. 关心，顾念虽放流，眷顾楚国，系心怀王。

作副词

  1. 反而，却表示转折。
  2. 难道人之立志，顾不如蜀鄙之僧哉？
  3. 只是，不过顾吾念之……徒以吾两人在也。

本句：顾……耳 = 只是……罢了

两个“之”同一个字，两种作用
用之代词指代前面的“讽谏、直谏”，可译为“它们”。
之术结构助词“的”连接“它们”和“方法”。

“用之”不能机械翻成“使用它”；前文同时出现“讽、直”两种方式，因此译作“使用它们”。

术本句的核心名词

方法、方式、策略。

“用之之术”就是“使用它们的方法”。“术”把讨论从“选讽还是选直”转到了“怎么用”。

何如固定结构

怎么样。

今日之事何如？《鸿门宴》：今天的事情怎么样？

耳句末语气词

罢了、而已，常用来把语气收轻。

“顾”与“耳”前后呼应，形成“只是……罢了”的固定表达，而不是“回头看”。
