# 任务提示词：地球仪「做大做细做有价值」升级

> 直接复制本文件给任意 AI 智能体 / 开发工具即可执行。所有结论都基于**实测**，不是假设。

## 一、项目背景（不可违背的硬约束）

| 约束 | 说明 |
|---|---|
| **零依赖、无构建** | 原生 JS + `<script>`。可以用**已 vendored 的库**（项目里已有 `vendor/three.min.js`、`vendor/anime.umd.min.js` 的先例），但**不许**引入 npm / 打包步骤 |
| **双击 `index.html` 可用** | 离线也必须能开。所有"仅联网"的功能必须有降级或明确提示 |
| **手机性能敏感** | 已有 `PERF` 分级（手机/低端机自动降 pixelRatio、降帧率、关特效）；离开页面必须停 rAF、释放 GPU 资源 |
| **国内网络可达性（已实测）** | ✅ 可通：`api.github.com`、`github.io`、`*.arcgisonline.com`(Esri 卫星瓦片，674ms)、`api.tianditu.gov.cn`、`webapi.amap.com`　❌ 不可通：`tile.openstreetmap.org`(超时)、`*.workers.dev`、`*.supabase.co`、`map.ovital.com`(不存在) |
| **`file://` 限制** | ① 本地图片不能上传为 WebGL 贴图（会 SecurityError）→ 现状用 base64 内联贴图绕过 ② 不能 fetch 本地 JSON |
| **不丢用户数据** | localStorage `gml_progress_v1`，有导出/导入 JSON 兜底 |

## 二、本次目标（用户原话拆解）

1. **做大做细做有价值** —— 让地球模块从"能转的展示球"变成**真正能用于高考地理备考**的工具
2. **尽可能无限放大** —— 能一直放大到看清街道/地形/河流
3. **合并**：把「地球运动」那个**没有地貌的纯色球**合并进「真实地球」，不要两个球
4. 备选探索（已实测排除）：搭载奥维地图 ❌（无网页版）；找现成网页版地图 ✅（见方案 B）

## 三、关键技术结论（必须先理解，否则方案会错）

### A. 单张贴图的球**无法无限放大**
球面 + 一张 2048×1024 贴图，放大 3 倍以上即模糊。这是分辨率上限，不是代码问题。

### B. 真正的"无限放大" = 瓦片金字塔
按 z/x/y 分层请求瓦片，放大时加载更高层级。**必须用在线瓦片源**（自建离线瓦片体积会到 GB 级）。

### C. 两种尺度必须并存，不是二选一
| 尺度 | 载体 | 独有价值 |
|---|---|---|
| **全球尺度** | three.js 球面 + 贴图 | 昼夜晨昏线、太阳直射点、大圆最短航线、自转、五带 —— **球面几何教学，平面地图做不到** |
| **局部尺度** | 瓦片地图 | 无限缩放看地形/河流/城市/等高线 —— **区域地理教学** |

## 四、要交付的三件事

### 交付 1 · 合并两个球（必做）
- 把现有 `#/globe` 里「地球运动」板块的**教学控件**（日期滑杆：春分/夏至/秋分/冬至/今日复位、直射点纬度、正午太阳高度、晨昏线、昼夜长短）搬到「真实地球」的 3D 球上
- **删除那个没有地貌的 2D 纯色球**（它的功能在 3D 球上全部已有）
- 5 个板块重组为 **3 个**：
  1. **地球（3D 球面）**：真实地貌 + 经纬网 + 五带 + 大洲大洋 + 昼夜晨昏线 + 直射点 + 时间/日期滑杆 + 大圆航线 + 点球面读数
  2. **卫星地图（瓦片）**：无限缩放（见交付 2）
  3. **专题**：大气与海洋 / 地质·气候·植被（原有卡片）
- 保留既有算法不动：昼夜/晨昏线按真实日期计算、正午太阳高度、地方时与时区、大圆距离

### 交付 2 · 瓦片地图（无限缩放）
**瓦片源优先级（均已实测可达）**：
1. **Esri World Imagery**（首选，立即可用、无需 key、674ms 实测）
   `https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}`
2. 天地图（需用户注册免费 tk，国内合规首选）
3. 高德（需 key）

**实现要求**：
- 允许 vendored 一个轻量瓦片库（**Leaflet 约 42KB**，与已有 three.js 的体量同量级）；**不要**引入 Cesium（3MB+，手机扛不住）
- 必须支持：滚轮 / 双指捏合 / ± 按钮 / 双击放大、拖拽平移、**显示当前缩放级别与经纬度**
- 断网或瓦片失败要有兜底文案（不能白屏）
- 与 3D 球共享"点击读经纬度 / 地方时 / 时区"的读数面板
- 提供**图层切换**：卫星影像 / 地形（Esri World Terrain 或 World Shaded Relief）/ 街道

### 交付 3 · 专题图层挂考点（在有内容的前提下）
- 每个图层开关旁标注对应高考考点，点击弹出：核心结论 + 易错点 + 典型考法
- 圆圈/标注**默认关闭**，按需开；**默认极简**（首屏只有真实地貌 + 经纬网 + 五带 + 大洲大洋）
- B 站视频挂接：需要用户提供 BV 号，否则留占位入口，不要伪造

## 五、明确不要做的事

- ❌ 引入 React / Vue / Tailwind / npm / 构建步骤
- ❌ 用 `tile.openstreetmap.org`（实测超时）
- ❌ 试图嵌入奥维地图（无网页版）
- ❌ 引入 Cesium / Mapbox GL（体积或 key 问题）
- ❌ 用 4096 或更大的贴图替换现有资源（现有 2048 已够；首屏体积要控）
- ❌ 破坏现有功能：导出/导入、离线可用、双击可用、手机性能分级

## 六、验收标准

1. **手机能捏合缩放** 3D 球，也能在瓦片地图上缩放到 z18 以上（能看清街区）
2. 首屏干净：只有真实地貌 + 经纬网 + 五带 + 大洲大洋，**没有**城市标签堆叠、没有默认航线
3. 3D 球上能通过日期滑杆看到**晨昏线随季节移动**，并读出直射点纬度
4. 瓦片地图与球面共用一套"读经纬度/地方时"面板
5. 断网时：3D 球正常（贴图已本地化），瓦片地图给出明确提示
6. 全站回归：`node --check` 全部通过、导出/导入仍可用、手机上不卡
